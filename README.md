# Semana 1 — GitHub y tu primer README

## README: qué es y por qué importa

El **README.md** es la “portada” de tu repositorio. Es lo primero que ve alguien cuando entra a tu proyecto en GitHub.  
Un buen README:

- explica **qué es el proyecto**
- muestra **qué aprendiste** o qué buscabas practicar
- ayuda a otros a entender **cómo usarlo**
- mejora tu **portafolio** (se ve más profesional y ordenado)

---
Hola mundo

## Markdown para README (mínimo)

Estos son los básicos que vamos a usar:

- `# Título` → Título principal
- `## Subtítulo` → Sección secundaria
- `- lista` → Listas
- `**negrita**` → Resaltar ideas importantes
- `` `código` `` → Mostrar comandos o fragmentos cortos

Ejemplo rápido:

# Mi Primer Repo

## Qué aprendí

- Crear repo
- Editar README
- Hacer commit

**Este texto está en negrita** y esto es `código`.

---

## Práctico: crear cuenta GitHub

1. Crear usuario (**nombre profesional** y fácil de recordar)
2. Verificar el email
3. Completar perfil (opcional): foto, bio corta, ubicación

---

## Práctico: crear repo + README

1. Ir a GitHub → **New repository**
2. Nombre: `mi-primer-repo`
3. Visibilidad: **Public**
4. Marcar: **Add README**
5. Click en **Create repository**

---

## Práctico: editar README y “commit changes”

1. Abrir `README.md`
2. Click en **Edit** (ícono del lápiz)
3. Pegar la plantilla de abajo
4. Click en **Commit changes**
